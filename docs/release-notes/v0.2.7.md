# WeChat Obsidian Publisher 0.2.7

## 中文

- 模板条目改为 36px 单行结构，只显示模板名和三枚真实配色条；来源与主色 HEX 移入悬停提示。
- 收藏按钮常驻，复制与用户模板操作在悬停或键盘聚焦时出现，129 套模板浏览更紧凑。
- 字号与四周 Padding 调节器进入独立的右侧保留区，展开模板库后也不会遮挡手机外框或正文。
- “复制并编辑”、阅读模式、设备模式、导入和常规工具按钮统一为 11px 字号和 28px 控件高度。
- 保留手机、微信和桌面模拟外框；外框内继续加载与微信草稿完全同源的发布 HTML。
- 30 项自动化测试通过，安装更新只替换 `main.js`、`styles.css` 和 `manifest.json`，不覆盖 `data.json`。

## English

- Template rows are now compact 36px single-line items with only a name and three real palette swatches. Source attribution and accent HEX move to the hover tooltip.
- Favorite controls remain visible while duplicate and custom-template actions appear on hover or keyboard focus.
- Font-size and all-side Padding controls now occupy a reserved right rail and cannot cover the phone frame or article when the library opens.
- Duplicate-and-edit, reading presets, device modes, import, and standard toolbar buttons now share 11px type and a 28px control height.
- Phone, WeChat, and desktop frames remain simulation-only; the content inside them still uses the exact publish HTML sent to WeChat.
- All 30 automated tests pass. Updating the installed plugin replaces only `main.js`, `styles.css`, and `manifest.json`, never `data.json`.
