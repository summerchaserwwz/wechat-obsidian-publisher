# v0.2.10

## 中文

### 这次修了什么

- 模板库不再因为整页刷新回到列表开头。选择模板、收藏、打开或收起模板库时，会按当前可见模板恢复滚动位置。
- 代码块改为真正写入最终文章 HTML 的 macOS 窗口结构。预览、检查页和微信草稿共享同一份代码块 DOM。
- 新增「Mac 代码手记」内置模板，适合左对齐技术长文。
- 用户模板编辑器新增 macOS 深色、macOS 浅色和朴素安全三种代码块预设，并支持显示或隐藏窗口栏、语言标签。
- 模板库扩展到 130 套，README 与演示截图同步更新。

### 兼容性

- 不依赖 `@wenyan-md/core`，Wenyan 主题仍以可追溯的内置 CSS 形式保留。
- 旧模板没有保存专属代码块配置时，会自动使用 macOS 深色预设。
- 旧的模板专属字号、内边距和 `data.json` 不会被覆盖。

### 验证

- 33 项测试通过。
- TypeScript 构建通过。
- 渲染测试覆盖预览与草稿 HTML 一致性，以及 macOS 代码块内联样式。

## English

### Changes

- The template rail no longer jumps to the top after a full workbench refresh. Selection, favorites, and drawer toggles restore the visible template anchor.
- Code blocks are now real macOS-style HTML windows in the prepared article document. Preview, checks, and WeChat drafts share the same DOM.
- Added **Mac Code Notes**, a left-aligned technical writing template.
- Added macOS Dark, macOS Light, and Plain Safe code profiles to the user-template editor, with switches for the window bar and language label.
- The catalog now contains 130 templates. README files and demo screenshots are updated.

### Compatibility

- The plugin does not depend on `@wenyan-md/core`; Wenyan themes remain bundled as traceable source CSS.
- Templates without an explicit code profile use macOS Dark automatically.
- Existing template-specific typography, padding, and `data.json` are preserved.

### Validation

- 33 tests passed.
- TypeScript build passed.
- Renderer tests cover preview-to-draft HTML parity and inline macOS code styling.
