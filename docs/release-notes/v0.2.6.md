# WeChat Obsidian Publisher 0.2.6

## 中文

- 模板导轨保留名称、来源、主配色色点和 HEX，收藏模板自动置顶。
- 阅读模式和设备外框移到预览右上角，不再打开单独的排版弹窗。
- 右下角新增常驻字号和四周 Padding 加减控制，并显示当前像素值。
- 新增手机、微信文章和桌面三种阅读外框；外框不进入发布 HTML。
- 默认手机排版调整为 16px 正文、1.78 行高、16px 段距、28px 标题留白和 10px 四周内边距。
- 预览继续使用与微信草稿相同的完整 HTML，发布后通过 `draft/get` 回读校验。
- 图片去重、受限并发上传和 Mermaid 去重处理缩短发布等待时间。
- AppSecret 持久化写入后立即回读确认；插件部署不会覆盖 `data.json`。

## English

- Template rows now keep the name, source, primary palette swatches, and accent HEX. Favorites are pinned first.
- Reading presets and device frames live in the upper-right preview toolbar instead of a separate layout modal.
- A persistent lower-right dock adjusts body font size and all-side Padding while showing the current pixel values.
- Phone, WeChat article, and desktop frames simulate the reading context without entering the published HTML.
- The default phone preset now uses 16px body text, 1.78 line height, 16px paragraph spacing, 28px heading space, and 10px padding on all sides.
- Preview continues to use the same complete HTML submitted to WeChat, followed by a `draft/get` parity check.
- Image deduplication, bounded concurrent uploads, and Mermaid deduplication reduce publish latency.
- AppSecret persistence is read back after storage, and plugin deployment never overwrites `data.json`.
