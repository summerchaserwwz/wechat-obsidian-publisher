# WeChat Obsidian Publisher 0.2.0

本版本完成 MD2 全量主题与内容模块兼容。

## 新增

- 完整接入 md2wechat-publisher 的 100 套主题，并保留来源与许可证元数据。
- 模板选择改为左侧紧凑浮窗，单色条展示主题，切换时不遮挡文章预览。
- 浮窗支持搜索、分组筛选、结果计数和来源展示。
- 支持正文前、首个表格前、首个表格后、正文后四个模块位置。
- 默认提供开头、表格前、表格后、结尾、往期推荐、作者介绍、关注卡片、版权声明和自定义模块。
- 内置模板可复制为用户模板并立即编辑。
- 支持真实 JSON 文件导入，兼容单模板、数组和模板包。
- 支持导出当前模板，以及批量导出全部用户模板。

## 安全与兼容

- 自定义模板导入会过滤危险选择器、不支持的属性和外部 CSS 资源。
- Wenyan AppSecret 会转存到 Obsidian `SecretStorage`，插件配置只保存引用。
- 微信请求改用 Obsidian 无跨域限制网络通道，覆盖连接检查、图片上传、草稿写入和回读。
- 微信 `40164` 错误会显示并支持复制被拒绝的 IP，同时提供公众号后台入口。
- 从 0.1.x 升级会保留已有模块、账号、草稿关联和用户模板，并补齐新模块。
- 仍然不依赖 `@wenyan-md/core`，主题由插件自己的编译器生成微信兼容内联样式。
