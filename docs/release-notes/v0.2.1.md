# v0.2.1：更安静、更顺手的发布工作台

这一版集中重做界面与交互，不改变文章渲染和微信发布协议。

## 界面

- 工作台改用 Obsidian 原生强调色，自动适配深色和浅色主题。
- 顶部操作降级，真实发布只保留在发布检查页，减少误触。
- 预览状态条更紧凑，模板、图片数量、设备宽度和复制操作集中在一行。
- 模块列表去掉重复卡片，改成连续列表；编辑和删除收进更多菜单。
- 模板库改成左侧可收起工具条，展开后占用独立布局空间，不覆盖文章预览。
- 发布检查加入就绪状态和更清楚的安全提示，窄侧栏会自动换行。

## 编辑体验

- 用户模板增加可视化编辑器，可直接修改主题色、画布色、标题色、正文色、字号、行距和字体。
- 编辑器右侧提供实时示意，高级 JSON 保留完整能力，并在保存前校验。
- 模块编辑器增加位置说明、启用开关、Markdown 示例和更明确的字段提示。
- 设置页按“文章默认值”和“公众号账号”分组，Wenyan 导入突出显示，手动添加默认收起。

## 安全说明

- AppSecret 继续由 Obsidian SecretStorage 管理，插件配置只保留引用。
- 系统钥匙串不可用时，界面不再宣称凭据一定经过系统级加密。
- 发布前确认和 `draft/get` 回读校验保持不变。
