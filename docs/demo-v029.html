Claude 删掉 80% 系统提示词，真正变化的是什么？

删掉 80% 系统提示词之后系统提示词 · CLAUDE.md · Skills · Agent Harness
PromptCLAUDE.mdSkillsTools

Anthropic 团队最近提到，在为 Claude Opus 5 调整 Claude Code 时，他们删掉了系统提示词中 80% 以上的内容，但没有看到可测量的性能损失。

真正发生变化的，是过去长期塞进系统提示词、CLAUDE.md、Skill 和插件说明里的内容，已经不再适合以常驻上下文的形式存在。

不是提示词失效，而是角色变了

提示词负责交代意图，系统负责提供边界，模型负责完成判断。手机阅读预设把正文控制在 15px，左右只保留 4px 内边距。
